# COMIM Training Platform

React frontend for the COMIM Freshwater Generator (FWG) training application — teacher, establishment admin, platform admin, student web module, and VR headset flows.

## Run

```bash
cd web
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).
